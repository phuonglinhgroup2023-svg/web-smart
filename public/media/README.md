# Media Assets

Place optimized WebP images and MP4 videos for hero background, product renders, and avatars in this directory.

Recommended naming:
- `hero-smart-furniture.mp4`
- `ai-desk-pro-1.webp`
- `zen-chair-x-1.webp`
- `avatar-1.webp`

Ensure assets are compressed and exported at 1440px width for desktop hero and 720px for carousel cards.
